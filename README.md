## Projetos

### [Bebedouro Inteligente](https://github.com/gsferreiira/bebedouro-inteligente)
Dispensação gravimétrica de água para copos e garrafas: sensores de presença e peso identificam o recipiente e controlam o enchimento automaticamente, com status exibido em display OLED.
`ESP32` `C++` `React` `Vite`
🔗 [Demo](https://bebedouro-inteligente.vercel.app/) · [Repositório](https://github.com/gsferreiira/bebedouro-inteligente)

### Ponte Elevatória Automatizada
Sistema de automação de uma ponte elevatória, com sincronização de 4 motores de passo e lógica *non-blocking* (`millis()`) para controle de movimento preciso e paradas de emergência.
`Arduino` `C++`
🔗 [Repositório](https://github.com/gsferreiira/blog_facul)
